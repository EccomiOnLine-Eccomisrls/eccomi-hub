# Barbara acceptance scenarios

- `Barbara` ranks matching clients when present in the data source.
- `Apri Decision Center` opens the Decision Center.
- `Posta` opens ECCOMI Posta.
- `Noleggio` opens ECCOMI Noleggio.
- `Nuova entry` opens the New Entry workflow.
- Partial words such as `nole` and `decis` return relevant results.
- Accented and unaccented forms are treated consistently.
- An empty query shows the highest-priority quick actions.
